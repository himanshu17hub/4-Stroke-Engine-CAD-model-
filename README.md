## 4-Stroke Engine Project

This repository contains the SolidWorks design files for a 4-stroke engine assembly. The project includes the main assembly as well as all the individual components used to construct the engine.

## Overview

The 4-stroke engine design includes detailed models for all the critical components. The main assembly file brings together all the parts to form the complete engine. The components included in this project are:

- **Assembly File:**
  - `4 stroke engine.SLDASM` – The complete engine assembly.

- **Part Files:**
  - `Crankshaft.SLDPRT` – The crankshaft component.
  - `Connecting rod.SLDPRT` – The connecting rod.
  - `Connecting rod cap.SLDPRT` – The cap for the connecting rod.
  - `Piston.SLDPRT` – The piston component.
  - `Piston pin.SLDPRT` – The piston pin.
  - `Piston ring.SLDPRT` – The piston ring.
  - `cover.SLDPRT` – The cover for the engine assembly.
  - `nut.SLDPRT` – The nut component.
  - `nail.SLDPRT` – A nail (used for assembly or simulation purposes).
